# Lea Michaelov — Portfolio 2026

Portfolio codebase for Lea Michaelov, focused on UX/UI, brand and digital design. Radware is the lead case study.

- Static HTML, CSS and JavaScript; no build step or dependencies.
- Vercel: framework `Other`, output directory `.`.
- Start with `index.html`; the Radware case study is at `case-studies/radware/`.
- Seven additional project overviews are rendered from `projects.js`.
- Figma iframe previews load on click. Public visibility follows each Figma file’s own sharing permissions.

The content and implementation plan is in [docs/PORTFOLIO_PRD.md](docs/PORTFOLIO_PRD.md). Project screens and fuller case-study narratives will be added iteratively.
