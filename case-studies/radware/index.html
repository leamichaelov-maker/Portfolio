The project

Radware was a large website and mobile design project that I handled end to end. My work brought together the client’s requirements and a refreshed approach to brand visualization.

The design language needed to carry different types of content while giving communication products a more modern visual presentation.

Building the
design language

I created a design language that balanced the client’s requirements with improvements to the product’s brand visualization.

This is the foundation of the case study: how the visual language connected the website and mobile experience, and how individual page types expressed it.

Different content.
Different treatment.

I differentiated use cases and articles within the design. Giving these content types distinct visual treatment was part of the broader website work.

Making products
more visual

I illustrated communication products with a more modern presentation for users, extending the design work beyond page layout into product visualization.
